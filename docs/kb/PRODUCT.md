# PRODUCT — Locator (locator_go)

**Updated (UTC):** 2026-07-28T11:59:44Z  
**Status:** bootstrap (уточнять с BA)

## One-liner

Админ-платформа мониторинга полевых устройств: карта, визиты/геозоны, чекпоинты, команды на Android-агент.

## Who it's for

- Операторы / админы (desktop UI)
- Полевые устройства (Android connector)

## Core jobs

1. Видеть устройства и локации на карте
2. Управлять визитами / чекпоинтами
3. Enroll устройств (QR / API key)
4. Отправлять device commands (config / app update и т.п.)

## Out of scope (пока)

- Публичный self-serve кабинет конечных пользователей
- Платежи / биллинг
- Formal BRD lifecycle визитов — см. audit P1 в `docs/knowledge-base/`
