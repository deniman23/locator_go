# Knowledge Base — Locator

Постоянная мультидоменная память аудитов для людей и AI-агентов.

## Назначение

Хранит результаты кросс-доменных проверок (BA, UX/UI, Frontend, Backend, QA, DevOps, Security) без перезаписи истории. Каждый прогон — новая папка в `audits/`.

## Структура

```text
docs/knowledge-base/
  README.md                 # этот файл
  INDEX.md                  # каталог всех отчётов (новые сверху)
  AGENTS.md                 # краткий гайд для AI-агентов
  audits/
    YYYY-MM-DD-full-audit/
      00-executive-summary.md
      01-business-analyst.md
      …
      99-consolidated-report.md
```

## Правила

- **Append-only**: не перезаписывать и не удалять прошлые аудиты.
- Если папка на сегодня уже есть — использовать суффикс `-2`, `-3`, …
- Не коммитить секреты, токены, пароли, содержимое `.env`.
- Перед новым аудитом читать `INDEX.md` и последний consolidated-отчёт.

## Команды

- `/full-audit` — полный прогон специалистов → отчёты в KB
- `/kb-study` — краткое резюме последнего аудита
- `/kb-init` — создать пустой каркас KB (если отсутствует)
