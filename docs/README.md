# Docs map — locator_go

Карта памяти проекта для людей и AI-агентов. **Не затирать** заполненные файлы — только дополнять.

| Путь | Назначение |
|------|------------|
| [`kb/`](./kb/) | Продуктовая и архитектурная документация (живая) |
| [`knowledge-base/`](./knowledge-base/) | Аудиты специалистов (append-only) |
| [`plans/`](./plans/) | Журнал работ AI и активные планы |
| [`stats/`](./stats/) | Сводки метрик / снимки состояния |
| [`TESTING.md`](./TESTING.md) | Как тестировать |
| [`AGENT_PHONE_SETUP.md`](./AGENT_PHONE_SETUP.md) | Провижининг устройств |

Корень репо: [`AGENTS.md`](../AGENTS.md) — операционные правила агента.

## Команды

- `/init-project-memory` — добить каркас памяти (без перезаписи)
- `/full-audit` — кросс-доменный аудит → `knowledge-base/`
- `/kb-study` — резюме последнего аудита
- Специалисты: BA / UX / FE / BE / QA / DevOps / Sec
