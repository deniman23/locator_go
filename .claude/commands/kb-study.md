# Study knowledge base

Изучи базу знаний проекта и кратко доложи состояние.

1. Прочитай `docs/knowledge-base/INDEX.md` и `docs/knowledge-base/AGENTS.md` (если есть).
2. Открой последний `audits/*/99-consolidated-report.md` (или укажи область из аргументов).
3. Суммируй: здоровье по доменам, открытые P0/P1, что уже устарело, что стоит перепроверить.
4. Не переписывай файлы KB, пока пользователь не попросит новый аудит.
